## Data

| Data | Used for | License |
|---|---|---|
| [DB-IP IP to City Lite](https://db-ip.com/db/download/ip-to-city-lite) | Country and city of public addresses. Downloaded at Docker build time, not stored in this repository. The UI shows the required attribution. | CC BY 4.0 |
| `src/test/resources/geoip/test-city.mmdb` | Test fixture with two fake ranges, generated by `scripts/make-test-geoip-db.py` | Same as this project |

CC BY 4.0 is a data license (attribution required), not a software license; it was chosen because the brief asked for DB-IP Lite specifically.
